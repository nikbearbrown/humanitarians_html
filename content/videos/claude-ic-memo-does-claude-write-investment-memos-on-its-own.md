Does the ic-memo skill write an investment committee memo on its own, the way a standalone app might? Not quite. Anthropic's ic-memo skill drafts a structured IC memo for private equity deal approval by synthesizing the due diligence findings, financial analysis, and deal terms a user provides, all from one instruction file that Claude reads and follows step by step.

## A skill is a folder, not an app

The first thing to understand is what a Claude Skill actually is: a folder Claude reads before it works, holding the full instruction set in one file, SKILL.md. There's no hidden logic separate from that file. Claude reads it, then acts on it. This matters for ic-memo specifically because it clarifies that the memo isn't being generated by some dedicated investment-memo application; it's Claude following a written specification.

## How the pipeline runs

The skill's steps live in a defined section of the file, and Claude reads each step in order and executes it. The process is linear, with no branching unless a step explicitly says to branch. For ic-memo, that means the same sequence of instructions executes every time, regardless of the specific deal.

## What the skill is actually built to do

The mechanism is a specification written as an instruction set: draft a structured investment committee memo for PE deal approval by synthesizing due diligence findings, financial analysis, and deal terms into one document. Because Claude follows exactly what's written, the result comes out the same way on every run, and the skill only covers what the file actually says. It doesn't reach beyond that scope to add analysis or judgment the file doesn't call for.

## What a skill does and doesn't add

A skill doesn't make Claude smarter in some general sense. It makes Claude follow a defined set of steps, in order, every time. For an IC memo, that's a meaningful and useful property: a partner reviewing memos across multiple deals can expect consistent structure and consistent synthesis logic, because the underlying process doesn't vary. What it doesn't provide is independent investment judgment about the deal itself; the memo reflects the diligence, financials, and terms fed into it, organized according to the file's instructions.
