MidJourney has grown well beyond typing a prompt and waiting for an image. Between the Create page and the Moodboard feature, there is now a real workflow for generating images, refining variations, and locking a project into a consistent visual style. This walkthrough goes through both, step by step.

## The Create page and the prompt bar

The Create option is where image generation happens, and everything starts at the top bar labeled "what will you imagine," where you type your prompt. That text is the starting point for whatever gets generated. From there, several tools sit alongside the prompt bar to shape the result.

## Add image, image prompts, and style reference

The add image option lets you upload a starting frame, either by clicking or by dragging and dropping a file, and MidJourney uses that image as a base for generating new ones. Image prompts work differently: you select multiple images from your gallery, and MidJourney looks at the elements inside them and blends those elements into the new creation when combined with your text prompt. Style reference is different again. It borrows the style of a selected image rather than its content. Select a painting and prompt for a modern skyscraper, and the generated skyscraper images come out rendered in the style of that painting.

## Omni reference for consistent characters

Omni reference is more specific than the other tools. It is built to generate a consistent person's face or character, ensuring MidJourney keeps those features consistent across multiple generated images, which matters for any project that needs the same character to appear more than once.

## Variations and animation

Once images generate, each one carries options for refining it further. The "very subtle" option produces variations with minor changes, while a stronger variation setting produces more dramatic differences from the original. The animate option converts a still image into a short video clip.

## Settings, search, and folders

A settings panel controls image size, such as portrait, square, or landscape, along with model mode (standard or raw), generation speed, and resolution, letting you tune both the aesthetic and the generation behavior. The search bar lets you find a previously generated image by typing keywords from the original prompt, which saves scrolling through a long history to find something specific. Folders round out the organization tools, letting you group images by name or by project, which becomes especially useful when multiple people are working across several projects at once.

## The Moodboard feature

The Moodboard section is built for a different purpose: collecting images and defining a consistent style for a project rather than generating one-off images. New moodboards can be created anytime, and images can be added either by uploading them directly or selecting them from your existing gallery. Inside a specific moodboard, you can upload images from your computer, add web links directly, or pull from the gallery.

## Setting a default and using a moodboard in prompts

Two settings make a moodboard actually useful in practice. The "set as default" option automatically applies that moodboard's style to every new image you create going forward. The "use in prompt" option works differently: it instructs MidJourney to apply the moodboard's defined style to a specific prompt you type in, giving you the moodboard's feel while still controlling the subject matter directly through your own words.

## Key takeaways

- The Create page's prompt bar is the starting point for every image, with add image, image prompts, and style reference as ways to shape the result beyond text alone.
- Style reference borrows the visual feel of a chosen image without copying its subject matter.
- Omni reference is built specifically for keeping a person's face or a character consistent across multiple generated images.
- Variations range from subtle to strong, and the animate option turns a still image into a short video clip.
- Moodboards collect reference images to define a consistent project style, either applied by default or invoked per prompt with "use in prompt."
- Folders and the search bar keep large, multi-project image libraries organized and easy to navigate.
