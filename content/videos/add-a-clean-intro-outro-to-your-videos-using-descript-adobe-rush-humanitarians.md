A video can have great content and still look unfinished without a clean intro and outro. This tutorial walks through exactly how to add both to an existing project video, using two different tools for two different jobs: Descript for the opening title card, and Adobe Rush for the closing branded logo.

## Building the intro title card in Descript

The process starts with a video that was already edited in Adobe Rush, then uploaded into Descript for the intro work. After opening Descript and uploading the video, clicking "edit the video" kicks off an automatic detection process that reads the lyrics or dialogue of the clip, which takes a couple of minutes to complete. From there, the Elements panel is where the actual title card gets built. Clicking on "title" adds a text box directly onto the video preview, where you can type whatever intro text fits the project, in this walkthrough, a simple label like "Animal Kingdom."

From that starting point, the title becomes fully customizable: font weight set to bold, size adjusted up to 150 or 200 to keep it readable, and a specific typeface, EB Garmon, chosen to match the project's style. Positioning matters here too, centering the text so it reads cleanly against the video behind it. Once the title looks right, expanding the timeline shows the title spanning the entire video by default, so the next step is trimming it down to just the first five to ten seconds, enough time for the intro to register without overstaying its welcome.

## Adding the branded outro in Adobe Rush

The outro works differently because it needs to live at the very end of the video and uses a static logo image rather than animated text. Before this step, the Humanitarians AI logo needs to be exported from its Figma board as a high-resolution PNG file. With that image ready, the same video project, now including the finished intro, is opened back up in Adobe Rush. Moving the timeline to the end of the video, clicking the plus icon and selecting media pulls up the downloaded logo file, which then gets added directly to the end of the timeline.

From there, the logo gets resized and repositioned so that it reads full-screen and center-aligned, giving the outro a clean, professional look rather than a small watermark tucked in a corner. A dissolve transition is added on top of that, set to run for around seven seconds, so the logo fades in smoothly rather than appearing abruptly. That combination, a full-screen centered logo with a gentle dissolve, is described as the standard approach used for Humanitarians AI project videos going forward.

## Why both tools matter together

The choice to split this work across Descript and Adobe Rush is practical rather than arbitrary. Descript's automatic transcription and element-based editing make it fast to build and style text overlays like a title card, while Adobe Rush handles image-based elements and transitions more directly. Combining the two lets a creator use each tool for what it does best rather than forcing one platform to do both jobs.

- Descript is used to build the intro title card, with the Elements panel providing text, font, size, and position controls.
