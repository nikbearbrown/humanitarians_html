## What a SREF code actually does

A Midjourney SREF, short for Style Reference, is a numeric identifier that locks in a specific visual treatment across generations. Instead of describing a style in words every time, you attach a short code to the end of your prompt and Midjourney applies that style's color logic, texture, and rendering approach to whatever subject you describe.
