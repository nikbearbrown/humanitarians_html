// SLIDE 21 — /APPLY-TO-JOB
/apply-to-job — the reference skill.
# /apply-to-job You are a job application specialist. ## Inputs - Job URL or pasted description - Target company name ## Workflow 1. Research company via web search (news, culture, tech stack) 2. Extract role requirements from posting 3. Read CLAUDE.md for candidate profile 4. Generate tailored CV (one page, PDF) 5. Generate cover letter (specific to role + company research) 6. Draft application email 7. STOP — present all materials for human review 8. On approval: save to /generated/[company-name]/ 9. Log application to tracker dashboard 10. Update memory: "Applied to [company] on [date]"

Each run takes 10–15 minutes instead of 45–60. Run it 5–10 times during your 2-hour application window. You review and approve — Claude handles the research, tailoring, and formatting. That's the "2" in 3-3-2.

Step 7 is the human gate. Nothing ships without your approval. Quality, not volume.

// SLIDE 25 — CONCEPT 16 · AUTOMATION
When there's no connector, use the browser.

Claude in Chrome is a Chrome extension that lets Cowork interact with websites directly — clicking, filling forms, navigating, extracting data.

Install from Chrome Web Store, toggle on in Cowork connectors. "Act without asking" mode for trusted tasks.

Use when
1
No connector exists

The target app isn't in Claude's built-in list or MCP registry

2
Web form application

The company has a custom portal, not Greenhouse/Lever

3
Data extraction

You need to scrape info from a page Claude can't search

Slower than a connector. But works on anything with a URL.
// SLIDE 26 — CONCEPT 17 · AUTOMATION
Claude on your desktop. Hands off the keyboard.

Computer use lets Claude control your actual computer — not just the browser, but any desktop application. Find files, open apps, drag and drop, fill forms in native software.

CONNECTORS
API-level integration. Fast, reliable, predictable. First choice.
CHROME EXT
Browser automation. Moderate speed. Works on any website. Second choice.
COMPUTER USE
Full desktop control. Slow but universal. Last resort.
Computer use is the nuclear option. Powerful, but save it for when nothing else works. Same tradeoff as REST API vs. Selenium vs. RPA.
