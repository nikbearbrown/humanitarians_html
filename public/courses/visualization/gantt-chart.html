What Makes a Gantt Chart Work — And the Four Layers of Information It Encodes

What this chart is

A Gantt chart encodes a project schedule as a two-dimensional table: tasks on the y-axis (categorical), time on the x-axis (ordinal or continuous date scale). Each task is represented as a horizontal bar whose position encodes start date, whose length encodes duration, and whose fill encodes phase membership. A partial fill within the bar encodes completion percentage — a fourth variable layered on the same visual element. The perceptual mechanism exploited is position along a common scale for date alignment, and length for duration comparison. Overlapping bars are immediately visible as parallel work; gaps in the schedule appear as empty horizontal space.

Four encoding layers

The Gantt chart stacks four distinct encodings onto a single rectangular element — which is both its power and its complexity ceiling. Position (x) encodes start and end date against a shared timeline. Length encodes duration. Fill color encodes phase category (with redundant stroke-width for critical path — a WCAG-compliant second channel). Partial fill encodes completion percentage — the complete portion is rendered at full opacity; the remaining portion at 0.28 opacity. A fifth layer — the dependency arrow — encodes sequencing relationships between tasks, which would be completely invisible in any other chart type.

What the alternatives would break

A timeline chart (single axis of events) handles dates but loses task duration and parallel execution — the critical project management signal that two tasks are running simultaneously disappears into a point. A table shows all data fields but destroys the spatial relationship between tasks: overlapping date ranges are invisible, and the critical path — which requires tracing the longest dependency chain — cannot be identified without computation. The Gantt chart makes both overlap and sequence perceptually immediate, without any arithmetic from the viewer.

Critical path and milestones

The critical path is the longest chain of dependent tasks — any delay in a critical task delays the entire project. This implementation marks critical tasks with a 1.5px obsidian stroke, redundantly encoded (color-independent) so the path is identifiable in monochrome output. Milestones are zero-duration events represented as diamond symbols — a geometric choice that distinguishes them from interval bars at a glance. The vertical dashed today line enables immediate triage: bars that should be complete (ending before today) but show incomplete fill are late tasks. No calculation required — the viewer reads the visual directly.

// FRAMEWORK REFERENCE

The FT Visual Vocabulary classifies Gantt charts under Processes & methods and Data over time: charts that show "how things work or change over time, especially sequential or parallel processes." Abela's framework routes here when the question is "when do these activities occur, and in what order?" — a fundamentally temporal question requiring a date-scale x-axis. Tufte's principle of the data rectangle is applied: every pixel of each bar encodes information (position, length, fill ratio). No decorative chrome — no drop shadows, no 3D bevels, no gradient fills that imply data variation where none exists. The alternating row tints use the hai palette's sky-faint (#F7FAFD) at minimal opacity — structural rather than decorative.

// The one design decision worth knowing

Dependency arrows use elbow connectors, not straight lines. A straight diagonal line from the end of task A to the start of task B crosses multiple task rows, creating visual noise that the viewer reads as additional data. The elbow connector — horizontal exit, vertical step, horizontal arrival — maps precisely to the logical structure of a finish-to-start dependency: exit the predecessor horizontally (task complete), traverse the row gap vertically (schedule relationship), arrive at the successor horizontally (task begins). When a successor starts before its predecessor finishes — the t09→t11 case here — the connector wraps rightward before stepping down, visually encoding the time-overlap risk without any annotation.
