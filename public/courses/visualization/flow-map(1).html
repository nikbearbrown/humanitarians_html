// What is a Flow Map?

A flow map draws directed lines between geographic origin and destination points, where the thickness of each line encodes the volume of movement between them. Viewers read two things simultaneously: the geographic path (where flows go) and the magnitude (how much moves). The critical perceptual contract — absent in a plain connection map — is that width is data. A thick ribbon means more displaced persons; a thin ribbon means fewer. The arrowhead at the destination tip encodes directionality, which a symmetric stroke cannot.

Flow maps are best suited to data with three simultaneous qualities: directionality (a source and a destination), volume (a quantity attached to each corridor), and geography (where the origin and destination actually sit in the world matters to the story). If any of those three qualities is absent or irrelevant, a different chart type — connection map, Sankey, or bubble map — is probably more appropriate. Width is scaled via a square-root transform so that perceived area is proportional to flow volume rather than just the raw width.

// learn — flow map (link map · ray map) 02 / 02

Why a Flow Map

What this chart is

A flow map draws directed lines between geographic points where the thickness of each line encodes the volume of the movement. The viewer reads two things simultaneously: the geographic path of a flow (where it goes) and its magnitude (how much moves). The key perceptual contract of a flow map — absent in connection maps — is that width is data. A thick ribbon means more; a thin ribbon means less. This is not decoration. The ribbon is a proportional symbol stretched along a path.

Flow maps sit in the FT Visual Vocabulary's Spatial / Movement category. They are the geographic equivalent of a Sankey diagram — except the node positions are geographic facts, not layout choices. The branching, ray-like structure from each origin is the signature visual pattern: flows spread outward from a single point like rays from a source, each ray's width encoding its own share of the total outgoing volume.

Why it was chosen here

The data has three simultaneous qualities that the flow map handles and no other chart type does: directionality (from crisis origin to host country), volume (magnitude of movement, which varies by orders of magnitude across corridors), and geography (the physical distance and direction of each corridor are meaningful — Syria→Turkey is a different story from Syria→Germany). Removing any of these qualities changes what you can read from the chart.

The connection map, built two sessions ago, handled a similar dataset but with a different message: it showed the structure of a logistics network where the volume difference between corridors was secondary. Here, the message is about which corridors dominate — Syria→Turkey's ribbon is more than four times wider than Syria→Germany's. That magnitude difference is the story, and a tapered ribbon makes it legible at a glance.

What the alternatives lose

A connection map would replace the tapered ribbon with a uniform-width stroke, encoding volume only through stroke-width — a weaker perceptual channel than area. The viewer would have to mentally compare line widths rather than areas, which is harder and less accurate. More critically, a connection map implies bidirectional relationships; a flow map implies directional movement. The arrowhead at the ribbon tip is a non-negotiable encoding for displacement data.

A Sankey diagram would encode volume accurately through ribbon width at every point in the flow, which is correct — but it would discard geography entirely. The fact that Uganda and Kenya both border South Sudan and receive its largest flows is visible in the flow map; in a Sankey it would be invisible. Geography is doing real analytical work here, not decoration.

A bubble map would show total outgoing displacement per origin as a circle — but would erase every destination, every corridor, and every directionality. You would see that Syria displaces more than Myanmar, but not where those people go or how those corridors distribute.

// framework — FT Visual Vocabulary

The FT Visual Vocabulary distinguishes flow maps from connection maps on directionality and volume encoding: use a connection map when the story is about network structure and link presence; use a flow map when the magnitude of each directed flow is the primary variable. The test: does the width of each line carry a data value? If yes, it's a flow map.

// design decision — tapered filled ribbons, not stroked lines

The flows are drawn as filled SVG paths — closed quadratic Bézier polygons that taper from a wide base at the origin to an integrated arrowhead at the destination. This matters for two reasons. First, stroke-width on an SVG path is constant along the entire length; a filled polygon can genuinely taper, which encodes the directionality of the flow in the shape itself (wide = origin, narrow = destination). Second, perceived area of a filled shape is a more accurate magnitude channel than perceived width of a stroked line — the same Flannery principle that governs bubble maps applies here. Width is scaled via d3.scaleSqrt() so that perceived area is proportional to the flow volume rather than the radius.
