What arc diagrams are — and when they break

What this chart is

An Arc Diagram places nodes on a single linear axis and draws connections as curved arcs above that line. The arc's height is determined by the horizontal distance between its two endpoints — far-apart nodes produce tall arcs; adjacent nodes produce shallow ones. Arc thickness encodes relationship strength or frequency. The perceptual mechanisms at work are stroke weight and spatial proximity — two pre-attentive channels that let the eye detect dominant connections before conscious reasoning begins.

Why it was chosen here

Co-occurrence data — characters sharing scenes, words appearing together, researchers co-authoring — has no intrinsic spatial arrangement. Forcing it into a 2D force-directed layout implies that node position carries meaning, which it does not. The arc diagram is honest: it admits the data is a list, not a map. Arc thickness maps cleanly to frequency counts. Node radius maps to total activity. Both encodings are readable without a legend once the axis is ordered correctly.

What a force-directed layout would break

A 2D force-directed graph places nodes wherever spring physics settle — a result that varies by run and initial conditions. It implies that proximity means relatedness, which for co-occurrence data is false. The arc diagram sacrifices cluster visibility (you cannot see communities as clearly as in a network layout) but gains honest encoding: the axis is stable, reproducible, and — critically — sortable. Reorder nodes by total connections to minimize arc crossing and expose hub structure. Try the sort toggle on slide 1.

Framework reference & the one decision worth knowing

// FT Visual Vocabulary + Abela

FT Visual Vocabulary: Relationship — Connection. Abela quadrant: Relationship (show connections between entities, not comparison or composition). Tufte: every pixel of arc thickness encodes a real value — the axis line itself is the only non-data ink.

The one design decision worth knowing: node order on the axis determines arc-crossing density. Ordering by total connections (descending) places hubs adjacent, reducing crossings for hub-and-spoke patterns. Alphabetical ordering maximises crossings. This implementation exposes a sort toggle on slide 1 so you can observe the difference directly.
